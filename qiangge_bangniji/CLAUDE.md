# 强哥帮你记 — 产品文档

## 一、项目概述

| 项目 | 说明 |
|------|------|
| **项目名称** | 强哥帮你记 |
| **项目定位** | Windows 桌面个人记账软件 |
| **目标用户** | 编程小白，日常需要管理个人开支的普通人 |
| **运行平台** | Windows 系统电脑 |
| **开发技术** | Python + Tkinter + SQLite |
| **核心口号** | 每一笔，强哥都帮你记着。 |

---

## 二、核心功能

### 第一期（必须实现）

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 记一笔 | 输入金额（元）、选择一级+二级分类、填写备注（可选）、选择日期（默认今天），点击保存 |
| 2 | 查看账单 | 列表形式展示所有记录，按日期倒序，显示：日期、分类、金额、备注 |
| 3 | 删除记录 | 删除某条记录，删除前弹出确认框 |
| 4 | 修改记录 | 修改已有记录的金额、分类、备注、日期 |
| 5 | 本月统计 | 显示本月总支出、日均支出、分类占比饼图 |
| 6 | 按分类筛选 | 按一级或二级分类筛选记录 |
| 7 | 日期范围查询 | 选择起止日期，查看该时间段内所有记录 |
| 8 | 数据导出 | 将记录导出为 Excel（.xlsx）文件 |

### 第二期（后续可加）

- 月度预算设置与提醒
- 按备注关键字搜索
- 数据备份与恢复
- 年度报表（各月支出趋势折线图）
- 多账户支持（现金、银行卡、微信、支付宝）

## 五、技术方案

### 已选方案：Python + Tkinter + SQLite

| 组件 | 选型 | 说明 |
|------|------|------|
| 编程语言 | Python 3.13 | Windows 自带安装，简单好学 |
| 界面框架 | Tkinter | Python 自带，无需额外安装 |
| 数据库 | SQLite | Python 自带，数据存在 .db 文件里 |
| 图表 | Matplotlib | Python 最流行的绘图库 |
| Excel导出 | openpyxl | 轻量级 Excel 读写库 |
| 打包工具 | PyInstaller | 把程序打包成单个 .exe 文件 |

### 方案对比历史（供参考）

当时比较了四个方案：
- Python + Tkinter（✅ 已选）：最简单、最稳、打包小
- Electron + Web：界面最漂亮，但安装包大（~120MB）、内存占用高
- C# + WPF：Windows 原生最流畅，但只能在 Windows 上跑
- Flutter：跨平台，但桌面端还不够成熟

## 七、项目规则（全程遵守）

### 规则一：技术选型必须先列方案
在任何技术决策点，必须先列出至少 2 个可选方案，对每个方案用通俗语言解释是什么、优点、缺点、适合谁，然后等待用户明确选择后再继续。

### 规则二：修改前先确认
对已有代码做任何实质性修改前，先说明要改什么、为什么改，等用户确认后再动手。

### 规则三：保持文件结构清晰
代码从一开始就分目录组织，不把所有代码堆在一个文件里。

### 规则四：逐模块交付
每完成一个功能模块就停下来让用户试用确认，确认后再继续下一个。

### 规则五：通俗解释
所有技术概念用通俗语言（比喻、举例）解释，不假设用户有编程背景。
